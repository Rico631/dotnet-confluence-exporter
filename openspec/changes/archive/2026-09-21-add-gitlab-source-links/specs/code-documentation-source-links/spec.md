# Spec Delta

## Purpose

Предоставляет пользователям Confluence-документации прямой переход к исходным файлам handler и методов, отображённых в дереве вызовов, в GitLab-репозитории.

## ADDED Requirements

### Requirement: Ссылка на исходный файл handler

Система SHALL отображать имя handler как ссылку на его исходный файл в GitLab, если задан GitLab repository URL и доступен относительный путь файла.

#### Scenario: Handler со ссылкой на GitLab

- **WHEN** рендерится документация handler с GitLab repository URL, reference и относительным путём исходного файла
- **THEN** имя handler отображается как ссылка на `/-/blob/{reference}/{relative-path}` указанного репозитория

#### Scenario: Недоступен путь handler

- **WHEN** задан GitLab repository URL, но относительный путь исходного файла handler отсутствует
- **THEN** имя handler отображается без ссылки и без ошибки рендера

### Requirement: Ссылки на исходные файлы call tree

Система SHALL отображать методы дерева вызовов как ссылки на соответствующие исходные файлы в GitLab, если задан GitLab repository URL и доступен относительный путь метода.

#### Scenario: Метод call tree со ссылкой на GitLab

- **WHEN** рендерится метод call tree с GitLab repository URL, reference и относительным путём исходного файла
- **THEN** отображаемое имя метода содержит ссылку на `/-/blob/{reference}/{relative-path}` указанного репозитория

#### Scenario: Методы из разных файлов

- **WHEN** call tree содержит методы из нескольких исходных файлов
- **THEN** каждый метод получает ссылку на свой соответствующий относительный путь

### Requirement: Безопасное формирование ссылок

Система SHALL корректно формировать GitLab URL для относительных путей с вложенными каталогами и специальными символами, не позволяя содержимому пути или reference интерпретироваться как HTML-разметка.

#### Scenario: Путь с вложенными каталогами и специальным символом

- **WHEN** относительный путь содержит несколько каталогов или символы, требующие URL-кодирования
- **THEN** ссылка сохраняет разделители каталогов, кодирует сегменты пути и остаётся валидным XHTML-атрибутом

### Requirement: Обратная совместимость без GitLab настроек

Система SHALL сохранять текстовое отображение handler и методов call tree, если GitLab repository URL не задан.

#### Scenario: Рендер без GitLab repository URL

- **WHEN** документация рендерится без GitLab repository URL
- **THEN** handler и методы call tree отображаются как обычный текст без ссылок
